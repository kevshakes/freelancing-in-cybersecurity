# Platform Setup Checklist (Upwork, Fiverr, Freelancer)

Use this before you apply to a single job. A half-finished profile gets ignored regardless of your skill level.

## Upwork

- [ ] Profile photo: real headshot, plain background, visible face — no logos
- [ ] Title: specific, not generic (e.g. "AI-Aware Phishing Simulation & Security Awareness Specialist" not "Cybersecurity Expert")
- [ ] Overview: 3–4 short paragraphs — problem you solve, proof, how you work, call to action
- [ ] Skills: add all relevant tags (pentesting, GRC, SOC, AWS Security, etc.) — Upwork's search relies on these
- [ ] Portfolio: at least 2 items — a writeup, a sanitized report sample, or a certificate
- [ ] Certifications: add every relevant one (AWS Security Specialty, CompTIA Security+, HCIP Security, etc.)
- [ ] Rate: set a real, considered rate — see `04-proposals-pricing/pricing-tier-guide.md`
- [ ] Availability: keep this current — clients filter by it
- [ ] Video intro (if available): huge trust boost, 60–90 seconds is enough

## Fiverr

- [ ] Gig title: keyword-first (clients search, they don't browse)
- [ ] Gig image/gallery: custom-made, not a stock template
- [ ] Packages: 3 tiers (Basic / Standard / Premium) with clear scope differences — see pricing guide
- [ ] FAQ section: pre-answer the 5 questions you'd expect from a first-time buyer
- [ ] Requirements: ask for exactly what you need to start (scope, target, access) — reduces back-and-forth

## Freelancer.com / Toptal

- [ ] Skills test scores: complete relevant tests if the platform offers them
- [ ] Portfolio uploads: same assets as Upwork, reused
- [ ] Toptal specifically: expect a multi-stage vetting interview — prepare a live technical walkthrough of one past project

## General profile hygiene

- Use the same headline and bio language across all platforms — consistency builds recognition
- Update your profile every time you complete a project or earn a certification
- Respond to messages within 24 hours during your first 90 days — response time affects ranking on most platforms
