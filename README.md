# Freelancing in Cybersecurity — Toolkit

Companion resource repo for the **"Prompts, Payloads & Paychecks: Freelancing in the Era of AI-Powered Cyber Threats"** session, hosted by Kevin Tuei for the ALX Cybersecurity Community — 10 September 2026.

This repo is built around what actually determines whether you get paid as a cybersecurity freelancer: your **personal brand**, your ability to **find and reach direct clients**, and your ability to **negotiate and hold your rate** once you're in conversation. Platforms are covered, but as a secondary option — not the main path.

## How to use this repo

Work through it in order if you're starting from zero, or jump straight to what you need:

| Folder | What's inside |
|---|---|
| [`01-linkedin-glowup/`](./01-linkedin-glowup) | **Start here.** Headline formulas, About section template, Featured section & banner checklist, 30-day content plan, positioning guide, bio templates |
| [`02-direct-client-outreach/`](./02-direct-client-outreach) | Finding direct clients without a platform, cold email scripts, LinkedIn outreach templates, a lead-list starter sheet |
| [`03-negotiation/`](./03-negotiation) | Rate negotiation guide, objection-handling scripts, scope creep & boundaries |
| [`04-proposals-pricing/`](./04-proposals-pricing) | Proposal templates, pricing tier guide, contract basics |
| [`05-ai-era-cheatsheet/`](./05-ai-era-cheatsheet) | AI-powered threat landscape one-pager, using AI tools to freelance faster |
| [`06-portfolio-building/`](./06-portfolio-building) | Writeup templates, CTF/cert showcase guide, building proof without paid clients |
| [`07-certifications/`](./07-certifications) | Top cybersecurity certifications overview + full ISACA guide (CISA, CISM, CRISC, CGEIT, CDPSE, and the new CCOA) |
| [`08-freelance-platforms/`](./08-freelance-platforms) | Optional/secondary — Upwork setup checklist, for if/when you also want to list on platforms |
| [`resources.md`](./resources.md) | Curated links — communities, certifications, learning resources |

## Quick start (tonight's session)

1. Pull up your current LinkedIn profile.
2. Rebuild your headline and About section using `01-linkedin-glowup/`.
3. Fill out your Featured section using the checklist in the same folder.
4. Identify 2-3 real direct-client leads using `02-direct-client-outreach/finding-direct-clients.md`.
5. Send one message today using a script from the same folder.
6. Before your next client call, skim `03-negotiation/rate-negotiation-guide.md` so you're ready to hold your rate.
7. Pick one certification to pursue from `07-certifications/` — ISACA's new CCOA is a strong fit if you're leaning toward SOC/incident response work.
