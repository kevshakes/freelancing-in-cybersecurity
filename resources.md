## Certifications worth exploring (varies by specialty)

See [`07-certifications/`](./07-certifications) for the full guide. Highlights:

- AWS Certified Security – Specialty — https://aws.amazon.com/certification/certified-security-specialty/
- CompTIA Security+ — https://www.comptia.org/certifications/security
- Certified Ethical Hacker (CEH) — https://www.eccouncil.org/train-certify/certified-ethical-hacker-ceh/
- ISC2 CC / CISSP (for more experienced practitioners) — https://www.isc2.org
- Huawei HCIP-Security
- **ISACA** — CISA, CISM, CRISC, CGEIT, CDPSE, and the new **CCOA (Certified Cybersecurity Operations Analyst)** — https://www.isaca.org/credentialing/ccoa

## Business/admin tools worth knowing

- A simple contract template tool or e-signature service for direct clients
- A basic invoicing tool if working outside platform payment protection
- A password manager and 2FA app — non-negotiable when handling client access
